## Animações
Primariamente utilizando CSS 3 para o controle das animações por meio de propriedades, como o opacity e transition, resultando na visibilidade. O Javascript também 
foi utilizado para analisar os cliques do usuário, por meio do addEventListener

## Busca e Filtro dos produtos
O javascript, através das funções de getElementByID, querySelector e filter, transformam e separam os objetos dos produtos, permitindo o usuário visualizar o que
precisa

## Sistema de paginação
Utilizando as funções de filter e slice, que retornam IDs do HTML e objetos do Javascript, o sistema de paginação separa quais produtos mostrar de acordo com a 
organização interna do site, assim como os filtros escolhidos pelo usuário
